### 应用路由器里有两种处理元数据的方式
{% folding, 静态元数据： %}
layout.tsx导出的元数据对它下面的所有页面都有效
page.tsx导出的元数据只对当前页面有效
两个有相同属性时page.tsx优先
```ts
import type {Metadata} from "next";
export const metadata: Metadata = {
  title: {
    default: "开发记录",
    template: "%s|开发记录"
  },
  description: "记录网站开发的流程",
  keywords: ["开发记录"],
  icons: {
    icon: "/favicon.ico"
  }
};
```
-  export const metadata ：通过  export  导出一个名为  metadata  的常量，Next.js 会自动识别并使用这个配置。
{% endfolding %}
<hr>
{% folding, 动态元数据： %}
//product/[productId]/page.tsx
```ts
import {Metadata} from "next";
type Props={params:{produtId:string}}
export const generateMetadata=async ({params}:Props):Promise<Metadata>=>{
  const productId=(await params).productId
  return {
    title:`产品详情${productId}`
  }
}
```
在同一个路由里不能同时使用静态和动态元数据
使用了"use client"的客户端页面不能使用元数据
{% endfolding %}
