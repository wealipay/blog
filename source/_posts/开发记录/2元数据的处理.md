### 应用路由器里有两种处理元数据的方式
{% folding, 静态元数据： %}
layout.tsx导出的元数据对它下面的所有页面都有效
page.tsx导出的元数据只对当前页面有效
两个有相同属性时page.tsx优先
```ts
//app/layout.tsx
import type {Metadata} from "next";
export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app"
};
```
-  export const metadata ：通过  export  导出一个名为  metadata  的常量，Next.js 会自动识别并使用这个配置。
{% endfolding %}

{% folding, 动态元数据： %}
//product/[productId]/page.tsx
```ts
import {Metadata} from "next";
type Props={params:{produtId:string}}
```
