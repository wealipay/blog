{% folding, @keyframes：%}
@keyframes是CSS中用于定义动画关键帧的规则，它能指定动画在不同阶段的样式变化，从而实现丰富的动画效果。
{% endfolding %}
<hr>
{% folding, 定义动画： %}
```ts
@keyframes 动画名称 {
  关键帧百分比 {
    /* 该阶段的样式 */
    属性: 值;
  }
  /* 可以有多个关键帧 */
}
------------------
@keyframes gradient {
  0% {
    background-position: 0% 50%;
  }
  50% {
    background-position: 100% 50%;
  }
  100% {
    background-position: 0% 50%;
  }
}
```
{% endfolding %}
<hr>
{% folding, 应用动画： %}
```ts
.animate-gradient {
  animation: gradient 3s ease infinite; /* 应用动画 */
}

```
{% endfolding %}
