路由处理程序能给指定的路由建立自定义请求数据，同一文件夹下有page.tsx和route.tsx,会被route.tsx接管，要注意处理冲突

{% folding, GET请求： %}
```ts
app/api/navs/navs.tsx 存放navs导航数据
export const navs = [
  { id: 1, title: "首页", href: "/" },
  { id: 2, title: "列表", href: "/products" },
  { id: 3, title: "领红包", href: "/tutorial" },
  { id: 4, title: "文档", href: "/docs" },
  { id: 5, title: "关于", href: "/about" }
];
app/api/navs/route.tsx 路由处理程序
import { navs } from "./navs";
export async function GET() {
  return new Response(JSON.stringify(navs));
}

```
new Response(JSON.stringify(navs))  是创建一个 HTTP 响应对象，并将  navs  数据以 JSON 格式返回给客户端的操作，具体含义如下：
 
-  JSON.stringify(navs) ：将  navs  这个 JavaScript 对象（或数组）转换为 JSON 格式的字符串。因为 HTTP 响应传输的是文本数据，所以需要把对象转为字符串才能传递。
​
-  new Response(...) ：创建一个标准的 HTTP 响应对象（符合 Web API 中的  Response  接口），并将上面转换后的 JSON 字符串作为响应体。
 
当客户端（如浏览器、Postman 等）请求这个接口时，就会收到这个响应，其中包含  navs  数据的 JSON 格式内容，客户端可以通过  JSON.parse()  将其转回对象进行处理。

{% folding, POST请求： %}
```ts
export async function POST(request: Request) {
  const body = await request.json();
  const newNav = {
    id: navs.length + 1,
    label: body.label,
    href: body.href
  };
  navs.push(newNav);
  return new Response(JSON.stringify(navs), {
    status: 201,
    headers: {
      "Content-Type": "application/json"
    }
  });
}
```
