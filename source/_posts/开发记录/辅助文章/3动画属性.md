{% folding, @keyframes：%}
@keyframes是CSS中用于定义动画关键帧的规则，它能指定动画在不同阶段的样式变化，从而实现丰富的动画效果。
{% endfolding %}
<hr>
{% folding, 定义动画： %}
```ts
@keyframes 动画名称 {
  关键帧百分比 {
    /* 该阶段的样式 */
    属性: 值;
  }
  /* 可以有多个关键帧 */
}
------------------
@keyframes gradient {
  0% {
    background-position: 0% 50%;
  }
  50% {
    background-position: 100% 50%;
  }
  100% {
    background-position: 0% 50%;
  }
}
```
{% endfolding %}
<hr>
{% folding, 应用动画： %}
```ts
.animate-gradient {
  animation: gradient 3s ease infinite; /* 应用动画 */
}

```
{% endfolding %}
<hr>
{% folding, animation： %}
```ts
animation: 动画名称 时长 缓动函数 延迟时间 循环次数 方向 填充模式 播放状态;

```
各参数说明（按顺序）
 
1. 动画名称（ animation-name ）
​
- 必须值，指定要使用的  @keyframes  动画名称（如  fadeIn 、 slide ）。
​
2. 时长（ animation-duration ）
​
- 必须值，指定动画完成一次循环的时间（单位： s  秒 或  ms  毫秒，如  1s 、 300ms ）。
​
3. 缓动函数（ animation-timing-function ）
​
- 可选，定义动画的速度变化曲线（如  ease  缓进缓出、 linear  匀速、 ease-in  加速）。
​
4. 延迟时间（ animation-delay ）
​
- 可选，指定动画开始前的延迟时间（单位同上，如  0.5s  表示延迟 0.5 秒开始）。
​
5. 循环次数（ animation-iteration-count ）
​
- 可选，指定动画循环次数（ number  具体次数， infinite  表示无限循环）。
​
6. 方向（ animation-direction ）
​
- 可选，定义动画是否反向播放（ normal  正向、 reverse  反向、 alternate  正反向交替）。
​
7. 填充模式（ animation-fill-mode ）
​
- 可选，指定动画结束后元素的样式（ none  不保留、 forwards  保留最后一帧、 backwards  延迟时显示第一帧）。
​
8. 播放状态（ animation-play-state ）
​
- 可选，控制动画播放/暂停（ running  播放、 paused  暂停）。
{% endfolding %}
