{% folding, 多路由布局： %}
如果想给应用的不同部分弄不同的布局，就要使用路由组
路由组能组织项目结构，不影响ui,而且还能给应用特定部分单独用布局，用(文件夹)表示
所有页面都必须嵌套在根布局（通常是  app/layout.tsx ）之下。根布局定义了整个应用的共享结构（比如 HTML、body 标签、全局样式、导航栏等），是页面渲染的基础。
{% endfolding %}
<hr>
{% folding, 注意事项： %}
{% note 1.使用(文件夹)组织项目结构 %}
{% note 2.每个多路由组需包含一个layout.tsx文件 %}
{% note 3.404页面只能放在路由组内 %}
{% note 4.所有(文件夹)下的一级目录只能包含一个page.tsx,如果有两个以上，会报错 %}
