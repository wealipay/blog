{% folding 基本操作:%}

- Alt D:复制物体，操作其中一个物体会同时影响另一个物体
- 7:顶视图
- Ctrl 7：底视图
- 质心点：两个或三个物体之间共同的点
- Shift S:游标 按住Shift加鼠标右键即可把游标放到指定位置
  {% endfolding %}
  {% folding 仙人球: %}
- Shift A:新建一个经纬球，右键平滑着色
- S Z：拉伸物体
- Ctrl Tab:进入编辑模式
- Alt 鼠标左键：鼠标为移动，模式为边时，Alt加鼠标左键，即可环选边
- GZ：移动环选的边
- O:开启衰减编辑模式，周围都会有影响，同时通过鼠标中键的滚轮放大或缩小衰减范围
- Shift 鼠标右键：把指针放到想要的位置，就能设置游标位置
- Ctrl R:环切命令，只有在编辑模式下才有，通过鼠标滚轮增加环切的数量，用在四边形的面上，不能用在三角锥上
- 横向环选：在编辑模式面下，按Alt 面与面之间的接线即可环选
- Alt E:弹出挤出选项
- Ctrl B:在编辑模式下针对边，进行倒角，倒角后可使用右键平滑着色或自动平滑着色
- Ctrl P:全选物体，按助Shift 鼠标点击物体即成为父级，操作父级可同时操作子级，Ctrl P即可设置父级
- Ctrl L:先选择需要材质的物体，最后选择已经有材质的物体，按Ctrl L选择关联材质即可
  {% endfolding %}

{% folding 圣诞树: %}

- Shift A:新建一个锥体
- SZ:压缩物体
- Ctrl A:应用缩放
- Shift Z:进入线框模式，同时开启透视模式
- Alt Z:从物体模式进入到半透明模式，同时开启透视模式
- 想环切锥体，进入透视模式后，全选，点击右键，选择细分即可环切锥体

{% endfolding %}
