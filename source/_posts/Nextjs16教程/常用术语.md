{% folding Link组件: %}
+ Link组件是内置组件，能实现预获取，还能保持滚动位置
#### 常见用法：
```tsx

import Link from "next/link";
export default function page() { 
  return (
    <div>
      <Link href="/running/data">跑步数据</Link>
      <Link href={{pathname:'/running/data',query:{id:1}}}>携带参数</Link>
      <Link href="/running/data?id=1">携带参数</Link>
    </div> 
  )};
```
- 在子组件中获取参数
```tsx
import {useSearchParams} from "next/navigation";
export default function page() { 
  const searchParams=useSearchParams()
  const id=searchParams.get("id")
  return (
    <div>
    {id}
    </div> 
  )};
```
