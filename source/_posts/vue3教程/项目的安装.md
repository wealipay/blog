{% folding 配置tailwindcss： %}
```ts
//vite.config.ts
import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
import tailwindcss from "@tailwindcss/vite"
// https://vite.dev/config/
export default defineConfig({
  plugins: [
    vue(),
    vueDevTools(),
    tailwindcss()
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
  },
})

```
<hr>
```ts
//main.css
@import "tailwindcss";
```

{% folding 样式重置： %}
```css
//assets/css/reset.css
* {
  @apply leading-none;
  @apply align-top;
}
html {
  @apply text-base;
  background: black;
  color: white;
}
html,body,#app {
  @apply h-full;
}
简单说就是“让所有元素行高为 1，且垂直方向顶部对齐”。
注意： @apply  是 Tailwind 特有的语法，用来将工具类“提取”到自定义 CSS 中，需要在支持 Tailwind 的项目中才能生效。
```

{% folding 调色板： %}
在 Tailwind CSS 中，
```css
@theme { --color-*: initial; }
```
这样的写法通常用于自定义主题中的 CSS 变量（自定义属性）。
- 作用：通过  @theme  规则可以扩展或覆盖 Tailwind 的默认主题配置，这里将所有以  --color-  开头的 CSS 变量重置为  initial （初始值），即取消 Tailwind 预设的颜色变量，让其使用浏览器默认的初始值。
- 使用场景：一般用于需要完全自定义颜色系统，不依赖 Tailwind 自带颜色变量时，先重置默认颜色变量，再重新定义自己的  --color-*  变量，以避免样式冲突。
```css
@theme {
  --color-primary: #3b82f6;
  --color-secondary: #10b981;
}
```
这样在项目中就能通过  text-primary  等类名使用自定义颜色了。
