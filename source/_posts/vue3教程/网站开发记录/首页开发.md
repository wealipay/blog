{% folding, v-bind: %}
在 Vue3 中， v-bind  是一个用于动态绑定 HTML 属性的指令，简单说就是把 Vue 实例（或组件）中的数据和页面元素的属性关联起来，让属性值能随着数据变化而自动更新。
 
核心作用
 
- 动态绑定属性：比如给  <img>  的  src 、 <a>  的  href 、元素的  class  或  style  等属性绑定数据。
​
- 响应式更新：当绑定的数据发生变化时，页面上对应的属性值会自动同步更新，不用手动操作 DOM。
 
基本用法
 
语法： v-bind:属性名="数据" ，可以简写成  :属性名="数据" （更常用）。
简单说， v-bind  就是 Vue 中“让数据驱动属性”的核心指令，是实现页面响应式的基础之一。

{% folding, 点击事件: %}
在 Vue3 中， @click  是用于绑定点击事件的指令，是  v-on:click  的简写形式，能快速实现元素点击后的逻辑处理。
 
基本用法
 
- 直接执行方法：在模板中通过  @click  绑定组件内定义的方法。
vue
```ts
<template>
  <button @click="handleClick">点击我</button>
</template>

<script setup>
  const handleClick = () => {
    console.log('按钮被点击了');
  };
</script>
 
​
```
- 传递参数：若需要向方法传递参数，直接在绑定的方法后加括号传入。
vue
```ts
<template>
  <button @click="sayHello('Vue3')">点击</button>
</template>

<script setup>
  const sayHello = (name) => {
    console.log(`Hello, ${name}`); // 输出：Hello, Vue3
  };
</script>
 
​
```
- 访问事件对象：若要获取原生事件对象（如获取点击坐标等），可传入  $event 。
vue
```ts
<template>
  <button @click="handleEvent($event)">点击</button>
</template>

<script setup>
  const handleEvent = (e) => {
    console.log(e.clientX); // 输出点击时的X坐标
  };
</script>
 
```
修饰符
 
 @click  支持事件修饰符，简化常见操作：
 
-  .stop ：阻止事件冒泡（相当于  e.stopPropagation() ）。
```ts
<div @click="parentClick">
  <button @click.stop="childClick">点击</button>
</div>
```
-  .prevent ：阻止默认行为（如阻止表单提交、链接跳转）。
```ts
<a href="https://vuejs.org" @click.prevent="handleClick">链接</a>
```
-  .once ：事件只触发一次。
```ts
<button @click.once="handleOnce">只触发一次</button>
```
