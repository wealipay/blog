{% folding, 模板： %}
模板在导航时为每个子项创建一个新的实例，用户在共享模板的路由之间导航时，将挂载子项的新实例，重新他们新的DOM元素，在客户端中不保留状态，并且重新同步效果
{% endfolding %}
{% folding, 布局和模板的差异： %}
在 Next.js 中，布局（Layout）和模板（Template）都是用于复用 UI 结构的功能，但核心差异在于 渲染行为和适用场景，具体如下：
 
1. 渲染行为：状态保留 vs 重新挂载
 
- 布局（Layout）：
布局在首次渲染后会 保留状态，后续页面切换时不会重新创建或卸载布局中的组件。
比如导航栏、侧边栏等全局 UI，切换页面时导航栏的状态（如展开的菜单、输入的搜索内容）会保留。
​
- 模板（Template）：
模板在每次页面切换时会 重新挂载内部组件（相当于“刷新”），状态不会保留。
比如需要在页面切换时重置的内容（如表单输入、临时状态）。
 
2. 适用场景
 
- 布局（Layout）：
适合复用 需要保留状态或长期存在 的 UI，例如：
​
- 全局导航栏、页脚
​
- 侧边栏（含折叠状态等）
​
- 全局数据（如用户登录信息）的展示组件
​
- 模板（Template）：
适合复用 需要在页面切换时重置 的 UI，例如：
​
- 页面级别的公共容器（如统一的卡片样式）
​
- 需要重新触发生命周期的组件（如每次进入页面都执行初始化的逻辑）
​
- 临时状态相关的 UI（如表单、倒计时器）
 
总结
 
核心区别：布局保留状态，模板重置状态。
 
- 想让组件在页面切换时“常驻”并保留状态 → 用布局。
​
- 想让组件在页面切换时“重新开始” → 用模板。
{% endfolding %}
