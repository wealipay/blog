{% folding RSC: %}

- Nextjs有两种渲染方式：
- {% folding 客户端组件: %}

  - 想要使用客户端组件，必须在文件的顶部加上"use client"指令
  - 客户端组件可以使用勾子，也能处理用户交互
    {% endfolding %}

- {% folding 服务端组件: %}
  - 默认情况下，Nextjs会把组件渲染成服务器端组件
  - 这些组件会执行服务端的任务，比如读取文件，直接从数据库获取数据
  - 但不能使用React Hooks,也不能处理用户交互
    {% endfolding %}

{% endfolding %}
