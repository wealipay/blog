{% folding 项目初初始化:%}

```
npx create-next-app@latest
```

{% endfolding %}
{% folding 生成公钥:%}

- 在 GitHub 上使用 SSH 密钥可以让你安全地连接仓库而无需每次都输入密码
- keygen是key generator（密钥生成器）的缩写，通常指用于生成加密密钥、许可证密钥或激活码的工具。

```
ssh-keygen -t ed25519 -C "1293600794@qq.com"
```

- 把生成的公钥复制到github上即可
- 测试连接：出现用户名即连接成功

```
ssh -T git@github.com
```

{% endfolding %}
{% folding 初始化远程仓库:%}

- 在github上新建blender仓库，初始化README.md文件
- clone代码到本地

```
git clone git@github.com:wealipay/blender.git
```

- 把在本地创建的nextjs项目删除README.md文件后，全部复制到仓库里

```
cp -r ./blenders/* ./blender
```

{% endfolding %}
{% folding 本地仓库与远程仓库关联: %}

```
//查看本地分支
git branch --show-current
//查看远程分支
git branch -r
//修改本地分支名
git branch -m master main
```

- 关联远程仓库：

```
git remote add origin git@github.com:wealipay/blender.git
```

- 验证远程仓库是否添加成功：

```
git remote -v
```
- 上传代码
```
git add .
git commit -m "初始化"
git push
```

{% endfolding %}
