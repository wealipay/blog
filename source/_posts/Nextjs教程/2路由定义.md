#### Nextjs使用文件系统的路由
创建 app 文件夹。然后，在 app 内部创建一个 layout.tsx 文件。此文件为 根布局。它是必需的，并且必须包含 `<html>` 和 `<body>` 标签。
``` ts
import React from "react";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```
创建一个包含一些初始内容的主页 app/page.tsx，只要文件夹中包含page.tsx的文件都是一个路由
``` ts
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```
当用户访问应用的根目录 (/) 时，layout.tsx 和 page.tsx 都会被渲染。
