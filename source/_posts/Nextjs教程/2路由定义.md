{% folding, 路由定义： %}
#### Nextjs使用文件系统的路由
创建 app 文件夹。然后，在 app 内部创建一个 layout.tsx 文件。此文件为 根布局。它是必需的，并且必须包含 `<html>` 和 `<body>` 标签。
``` ts
import React from "react";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```
创建一个包含一些初始内容的主页 app/page.tsx，只要文件夹中包含page.tsx的文件都是一个路由
``` ts
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```
当用户访问应用的根目录 (/) 时，layout.tsx 和 page.tsx 都会被渲染。

{% endfolding %}
<hr>
{% folding, 路由的三约定： %}
* 所有路由都必须放在app文件夹中
* 路由文件必须命名为page.tsx或page.js
* 每个文件夹代表url路径的一段
{% endfolding %}

{% folding, 嵌套路由/动态路由： %}
应用路由器里的每个页面都会通过params接收路由参数
```ts
export default async function ProductDetail({
  params
}: {
  params: Promise<{ productId: string }>;
}) {
  const productId = (await params).productId;
  return <div>{productId}</div>
}

```
这段代码是一个使用Next.js 13+ App Router语法的React组件，用于展示产品详情页，主要功能和语法解析如下：
 
1. 组件定义
 
javascript
  
export default async function ProductDetail(...)
 
 
-  export default ：将该组件设为默认导出，方便其他模块导入使用。
​
-  async ：标记该组件为异步组件，支持在组件内部使用 await 语法（这是Next.js 13+ App Router的新特性，允许组件直接处理异步数据）。
 
2. 参数类型定义
 
javascript
  
({ params }: { params: Promise<{ productId: string }> })
 
 
- 组件接收一个参数对象，其中包含 params 属性。
​
- TypeScript类型注解： params 是一个Promise对象，最终会解析为一个包含 productId （字符串类型）的对象。
​
- 这里的 params 来自Next.js的路由参数，比如当访问 /products/123 时， productId 会被解析为 "123" 。
 
3. 获取路由参数
 
javascript
  
const productId = (await params).productId;
 
 
- 由于 params 是一个Promise，使用 await 等待其解析，获取到包含 productId 的对象。
​
- 提取 productId 的值（即路由中的产品ID，比如 "123" ）。
 
4. 组件返回内容
 
javascript
  
return <div>{productId}</div>
 
 
- 组件渲染一个 <div> ，其中显示获取到的 productId （即路由中的产品ID）。
 
总结
 
这个组件是Next.js中用于动态路由详情页的基础结构：
 
- 通过路由参数 productId 识别具体产品（比如 /products/abc123 中的 abc123 ）。
​
- 利用 async/await 处理异步获取的路由参数（Next.js 13+的新特性）。
​
- 最终渲染出产品ID，实际开发中通常会根据 productId 进一步请求产品详情数据并展示。
