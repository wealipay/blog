```
npx create-next-app@latest
```

{% endfolding %}
{% folding 生成公钥:%}

- 在 GitHub 上使用 SSH 密钥可以让你安全地连接仓库而无需每次都输入密码
- keygen是key generator（密钥生成器）的缩写，通常指用于生成加密密钥、许可证密钥或激活码的工具。

```
ssh-keygen -t ed25519 -C "1293600794@qq.com"
```

- 把生成的公钥复制到github上即可
- 测试连接：出现用户名即连接成功

```
ssh -T git@github.com
```

{% endfolding %}
{% folding 初始化远程仓库:%}

- 在github上新建blender仓库，初始化README.md文件
- clone代码到本地

```
git clone git@github.com:wealipay/blender.git
```

- 把在本地创建的nextjs项目删除README.md文件后，全部复制到仓库里

```
cp -r ./blenders/* ./blender
```

{% endfolding %}

{% folding cp -r: %}

```ts
-  cp ：是“copy（复制）”的缩写，基础功能是复制文件/文件夹；
-  -r ：表示“recursive（递归）”，必须加在复制文件夹时，否则无法复制文件夹内的子文件/子文件夹；
-  ./next16/* ：源路径， ./  指当前目录， next16  是源文件夹， *  代表“该文件夹下所有内容”（不含  next16  文件夹本身）；
-  ./nextjs16 ：目标路径，若  nextjs16  已存在则直接覆盖内部对应内容，若不存在会自动创建该文件夹再复制。
```

{% endfolding %}

{% folding 本地仓库与远程仓库关联: %}

```
//查看本地分支
git branch --show-current
//查看远程分支
git branch -r
//修改本地分支名
git branch -m master main
```

- 关联远程仓库：

```
git remote add origin git@github.com:wealipay/blender.git
```

- 验证远程仓库是否添加成功：

```
git remote -v
```

- 上传代码

```
git add .
git commit -m "初始化"
git push
```

{% endfolding %}
