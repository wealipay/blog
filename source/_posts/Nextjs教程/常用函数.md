{% folding useState:%}

- useState 是 React 中的一个 Hook，用于在函数组件中添加和管理状态。
- 核心作用：

1.  让函数组件也能拥有“状态”（比如计数器、输入框内容等）。
2.  当状态发生变化时，组件会自动重新渲染，页面也会更新。

- 关键点：
  1. useState 返回一个数组，第一个元素是当前状态值，第二个是更新状态的函数。
  2. 每次调用 setCount，组件都会重新渲染。
     {% endfolding %}

{% folding useEffect: %}

- useEffect 是 React 中的一个 Hook，用于处理组件的副作用。
- 核心作用：
  1. 可以在函数组件中执行数据获取、订阅、DOM操作等“副作用”操作。
- 关键点:
  1. useEffect 第一个参数是要执行的函数。
  2. 第二个参数是依赖数组，控制什么时候执行副作用。空数组表示只在挂载和卸载时执行
  3. 可以返回一个清理函数，用于取消订阅或清理资源。
     {% endfolding %}

{% folding Suspence: %}

- Suspense 是 React 16.6+ 引入的组件，用于等待异步操作完成（如数据请求、组件懒加载），并在等待期间显示占位内容（loading），避免页面卡顿或空白。
- Next.js 扩展：支持  loading.tsx  自动配合 Suspense 实现路由级加载状态，无需手动包裹。
- fallback: 指定在组件加载或数据获取过程中展示的组件或元素
```ts
import { Suspense, lazy } from 'react';
// 懒加载组件（异步加载）
const LazyComponent = lazy(() => import('./LazyComponent'));

function App() {
  return (
    <Suspense fallback={<div>加载中...</div>}>
      {/* 异步组件会在加载完成后渲染 */}
      <LazyComponent />
    </Suspense>
  );
}

```

{% endfolding %}
