{% folding 什么是国际音标: %}
+ 英语单词就用国际音标来标记怎么读。相当于汉语的拼音一样。
+ 单词是写出来的字母；音标是读出来的声音。音标是一套特殊符号，写在两条斜杠  / /  中间，用来标注单词读音

{% folding 元音字母和辅音字母: %}
+ 英语一共26个英文字母
✅元音字母：5个：a  e  i  o  u
✅辅音字母：21个：b c d f g h j k l m n p q r s t v w x y z
⚠️注意：y 是半元音字母
1. 在单词末尾，做元音：baby，y发元音 /i/
2. 在单词开头，做辅音：yes，y发辅音 /j/

{% folding 不定冠词: %}
+ a和an叫不定冠词。
  简单说：用来表示“一个”，用在可数名词单数前面。
+ 1、作用：表示泛指「某一个」
  告诉别人：是一个东西，但不特指哪一个。英语可数名词单数，前面一般不能光秃秃直接用，要搭配 a/an / my / this 这类。
+ an 用在元音音素开头单词前面，读起来顺口，不拗口
+ a 用在辅音音素开头前面。
+ 1️⃣复数名词，不用a/an
👉意思一样，只是为了朗读顺口才分出 a 和 an。
{% note,  怎么确定用 a 还是 an%}
✅核心规则：看单词【第一个音素（读音、音标）】，不是看首字母！
 
- 单词开头是元音音素 → 用 an
​
- 单词开头是辅音音素 → 用 a
 
不要看字母是不是 a e i o u，要看读出来的第一个声音！
 
一、元音音素开头 → an
 
元音音素：20个元音音标。
 
 
 
hour 字母h开头，但是h不读，第一个声音是元音，所以用an。
 
二、辅音音素开头 → a
 
28个辅音音素。
 
 
 
university 首字母u（元音字母），但读音第一个音是 /j/，/j/是辅音音素，所以用a。
 
三、两组极易考对比（记牢）
 
1. ✅ a university
✅ an umbrella /ʌmˈbrelə/
 
同样u开头：
university读 /j/ 辅音 →a；
umbrella开头 /ʌ/元音 →an。
 
2. ✅ an hour（h不发音）
✅ a house /haʊs/（h要发音，辅音）
🚩做题三步法（考试直接套用）
 
1. 读出这个单词，看第一个读音（音素），不要看字母；
​
2. 第一个声音是元音 → an；
​
3. 第一个声音是辅音 → a。
